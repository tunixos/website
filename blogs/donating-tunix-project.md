# How to Financially Support the Tunix Project

Tunix is an independent operating system project focused on building a modern, lightweight and Linux-compatible system with its own userspace, package ecosystem and development roadmap.

Maintaining Tunix takes time and resources. Donations help support development, infrastructure, testing hardware, build servers and other costs required to keep the project moving forward.

## Why Support Tunix?

Your support directly helps with:
    
    * Development of the Tunix kernel and userspace
    * Porting and maintaining software packages
    * Build servers and project infrastructure
    * Hardware for testing drivers and graphics
    * Improving documentation and developer tooling
    * Keeping Tunix independent and community-driven
    
Even a small donation helps. If you like the idea of an independent operating system built from the ground up, supporting Tunix is a way to help make that idea real.
